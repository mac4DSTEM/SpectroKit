# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue. Use GitHub's private vulnerability reporting: open the
**Security** tab of this repository and choose **Report a vulnerability**.

Relevant reports include memory-safety problems or crashes triggered by a crafted spectrum or data file, since SpectroKit reads
Gatan DM and Velox EMD files through FormatoKit.

Please include the version, how to reproduce the problem, and a sample file if you can. This is a volunteer-maintained project,
so there is no guaranteed response time, but reports are taken seriously and will be acknowledged as soon as possible.

Only the latest release receives fixes.
